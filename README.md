# TODO App
----------------------
This is a simple TODO app with basic task management functionality, covering both frontend and backend.

## Tech Stack
--------------------
### Frontend

* React (Vite)
* TypeScript
* Tailwind CSS
* React Query
* Axios

### Backend

* Node.js
* Express.js
* MongoDB (Atlas)
* Mongoose

--------------------
## Project Structure

todo-app/
  |- client/   # React application
  |- server/    # Express API

--------------------
## Instructions

1. Clone the repository.
2. Setup Frontend and backend with the use of .env files.
3. Able to manage CRUD operations related to tasks.
--------------------
## Features

* Create, Edit, Delete Tasks
* Pagination
* Mark tasks as resolved/open
